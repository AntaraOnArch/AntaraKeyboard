Hello!
This is my first attempt at building a functioning Android app.
I decided it would be a keyboard after seeing that the Samsung keyboard takes 1 GB, so I made my own with no trackers, spyware, keylogging or anything like that.
I'm trying to keep it simple, since my knowledge isn't the best.
A lot of ideas and so little time to realize them, since I can only work on the app in my free time.

Current features:
  - swipe up for a capital letter
  - swipe left to delete text, swipe right to restore it
  - 3, 4 or 5 rows and 4 key shapes (hexagon, triangle, circle, cube)
  - customizable letter layout (key positions and long press)
  - customizable numeric layout (which symbols it has and their long press)
  - custom characters, emoji and whole texts on long press
  - programmable side buttons
  - colors for every part of the keyboard, light / dark / transparent / RGB themes
  - landscape layout with a customizable middle "island"
  - emoji picker
  - Latin, Cyrillic and Greek scripts, the app in 35 languages
  - optional word suggestions (offline, nothing typed is stored)

Future features:
  - minor bug fixes and design updates
